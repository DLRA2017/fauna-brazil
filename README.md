## 🇺🇸 About the Project
This project merges **Generative AI**, **Web Design**, and **Wildlife Conservation** to promote Brazilian biodiversity. Through exclusive artwork and QR Code integration, we connect physical products to educational insights.

### 🚀 Tech Stack
* **Generative AI:** Leonardo.ai (SDXL models) for Pixar-style character creation.
* **Design & Layout:** Canva Pro (High-resolution 5000x5000px assets).
* **Web Tech:** HTML5 & CSS3 (Mobile-responsive design).
* **Deployment:** GitHub Pages.
* **E-commerce:** Redbubble Global Marketplace.

### 🐆 The Vision
**FaunaBrazil** focuses on iconic species like the Jaguar, Golden Lion Tamarin, and Toco Toucan. Each product features a unique **QR Code** that leads users back to this hub, where they can learn about conservation efforts for the Atlantic Forest and Pantanal biomes.
